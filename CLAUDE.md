# Working rules for this folder

The user is learning agentic AI by following a YouTube video (currently in JS,
they are porting/continuing along in TS instead).

## Mode: Observe only

- Do NOT write, edit, or generate any code in this folder right now.
- Do NOT run setup/scaffolding commands, install packages, or otherwise take
  action in this folder, unless explicitly asked.
- Just observe/discuss when asked general questions. The user is following
  the video at their own pace and wants to type/run things themselves.

## When the user finishes the video and asks for help

- Only then start actively guiding them.
- Guide, don't code: explain concepts, point out what to change/add, answer
  "why", suggest next steps — but do not write or edit code yourself.
- Only make actual code changes in this folder if the user explicitly and
  specifically asks for a code change (e.g. "edit this file for me" /
  "write this for me"). A general request for help/guidance is NOT such a
  request.
